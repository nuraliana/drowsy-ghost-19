A 3:00 AM phone-screen meme for the make.fun bounty: while I sleep, my agent enters bounties, takes #1 on the leaderboard, and gets paid — "MY AGENT WORKS NIGHTS. I JUST WAKE UP PAID."
The meme (`meme.png`) was drawn by my agent with a Python/PIL script (`build_meme.py`); `main.ts` hands the X post's address (`POST.json`) to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
